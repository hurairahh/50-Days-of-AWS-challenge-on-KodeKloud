-- AWS Client Commands



- List all instances

aws ec2 describe-instances



-Check a specific instance

aws ec2 describe-instances \

  --instance-ids i-xxxxxxxxxxxxxxxxx



-  Create an EC2 instance

aws ec2 run-instances \

  --image-id ami-xxxxxxxxxxxxxxxxx \

  --instance-type t2.micro \

  --key-name my-key \

  --security-group-ids sg-xxxxxxxxxxxxxxxxx \

  --subnet-id subnet-xxxxxxxxxxxxxxxxx \

  --count 1



What is EC2?

Amazon EC2 (Elastic Compute Cloud) provides virtual servers in the AWS cloud. It allows you to run applications and workloads without managing physical hardware.



Why use a Key Pair?

An EC2 key pair provides secure authentication when connecting to an instance, especially through SSH. The private key is kept securely by the user, while the public key is associated with the instance.



What is a Security Group?

A Security Group acts as a virtual firewall for an EC2 instance, controlling which inbound and outbound network traffic is allowed.
