Day 12 of 50 Days of AWS Challenge on KodeKloud.

The task involved attaching the existing datacenter-volume EBS volume to the datacenter-ec2 instance in the us-east-1 region, using the device name /dev/sdb.

What is an EBS Volume?
Amazon EBS (Elastic Block Store) provides persistent block storage for EC2 instances. It can be used to store application files, databases and other data.

Why attach an EBS volume to EC2?
Attaching an EBS volume gives an EC2 instance additional persistent storage that can be managed independently from the instance itself.

What is /dev/sdb?
/dev/sdb is the device name assigned to the attached storage volume. It allows the operating system to identify and access the additional disk.
