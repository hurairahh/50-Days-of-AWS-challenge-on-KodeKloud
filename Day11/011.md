Day 11 of 50 Days of AWS Challenge on KodeKloud. 
Today’s task focused on AWS Elastic Network Interfaces (ENIs) and EC2 networking.

What is an ENI?
An Elastic Network Interface (ENI) is a virtual network interface that allows an EC2 instance to communicate with resources on a VPC network. It can have private IP addresses, security groups, and other network-related properties.

Why attach an ENI?
Attaching an ENI allows an EC2 instance to use a specific network interface and its associated network configuration. This can be useful for managing network connectivity and designing more flexible AWS architectures.
