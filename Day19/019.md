The task involved attaching the existing IAM policy iampolicy_kareem to the IAM user iamuser_kareem.

What is attaching an IAM Policy?
Attaching a policy to a user grants that user the permissions defined in the policy. These permissions determine which AWS resources the user can access and what actions they can perform.

Why use IAM Policies?I
AM policies provide a structured way to control access to AWS resources. Instead of giving users unrestricted access, specific permissions can be assigned based on their responsibilities.
