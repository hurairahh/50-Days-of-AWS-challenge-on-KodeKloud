Day 05 of 50 Days of AWS Challenge on KodeKloud.
Today’s task focused on Amazon EBS (Elastic Block Store) and cloud storage.
The task involved creating an EBS volume with the following configuration:
Name: xfusion-volume
Type: gp3
Size: 2 GiB

-- AWS Client Commands

- Show volumes 
aws ec2 describe-volumes

- Check a specific volume
aws ec2 describe-volumes --volume-ids

Create it with a name tag

aws ec2 create-volume \
 --availability-zone us-east-1a \
 --size 10 \
 --volume-type gp3 \
 --tag-specifications 'ResourceType=volume,
Tags=[{Key=Name,Value=MyVolume}]' 

What is an EBS Volume?
Amazon EBS is a block storage service designed to provide persistent storage for EC2 instances. It works similar to a hard drive that can be attached to an EC2 instance for storing applications, files and data.

What is gp3?
gp3 is a general-purpose SSD volume type that provides a balance of performance, reliability and cost, making it suitable for many common workloads.
