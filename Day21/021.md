Day 21 of 50 Days of AWS Challenge on KodeKloud.

The task involved creating an EC2 instance named xfusion-ec2 using a Linux AMI with the t2.micro instance type, then creating and associating an Elastic IP named xfusion-eip with the instance.

What is an Elastic IP?
An Elastic IP is a static public IPv4 address that can be associated with an AWS resource such as an EC2 instance. Unlike a dynamically assigned public IP, it provides a consistent public address.

Why use an Elastic IP?
A stable public IP can be useful for applications or services that need a consistent network endpoint, such as when users or external systems need to connect to a server reliably.
