Day 09 of 50 Days of AWS Challenge on KodeKloud.
The task involved enabling Termination Protection for the existing nautilus-ec2 instance in the us-east-1 region.

-- AWS client commands used
aws ec2 describe-instance-attribute \
 --instance-id i-04b6bc181d97545e4 \
 --attribute disableApiTermination

🛑 What is Termination Protection?
Termination Protection is an EC2 feature that helps prevent an instance from being accidentally terminated (deleted). When enabled, the instance cannot be terminated until the protection is disabled.

🔐 Why is it useful?
It provides an additional safeguard for important EC2 instances and helps prevent accidental deletion of resources and potential data loss.
