Today’s task focused on AWS VPC networking and subnet configuration.
The task involved creating a subnet named datacenter-subnet under the default VPC.

What is a Subnet?
A subnet is a smaller network within a VPC that allows AWS resources such as EC2 instances to be organized and managed within a specific IP address range, understanding VPCs and subnets is essential for designing and managing AWS network infrastructure. Subnets help organize resources and control how they communicate within a cloud environment.

 ---Aws client command

- List all subnets
aws ec2 describe-subnets

- List all subnets in a specific VPC
aws ec2 describe-subnets --filters "Name=vpc-id,Values=<your-vpc-id>"
