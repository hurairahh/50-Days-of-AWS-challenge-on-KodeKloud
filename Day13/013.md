What is an AMI?
An AMI (Amazon Machine Image) is a template used to launch EC2 instances. It can contain the operating system, applications, configurations and other settings from an existing instance.

Why create an AMI?
AMIs make it easier to create new EC2 instances with the same configuration, which is useful for backups, scaling, testing, and deploying consistent environments
