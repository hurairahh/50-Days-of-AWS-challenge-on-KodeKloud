Day 07 of 50 Days of AWS Challenge on KodeKloud.
The task involved changing the instance type of the nautilus-ec2 instance from t2.micro to t2.nano after ensuring its status checks were completed. The instance was then verified to be in a running state.

-- AWS Client Commands Used

- Change t2.micro to t2.nano
aws ec2 modify-instance-attribute \
  --instance-id i-049f0dd16528d92b4 \
  --instance-type "{\"Value\":\"t2.nano\"}"

-  Start the instance
aws ec2 start-instances --instance-ids i-049f0dd16528d92b4

-  Verify the new type
aws ec2 describe-instances \
  --instance-ids i-049f0dd16528d92b4 \
  --query 'Reservations[*].Instances[*].[InstanceId,InstanceType,State.Name]' \
  --output table

What is an EC2 Instance Type?
An instance type determines the computing resources available to an EC2 instance, such as CPU, memory and network performance. Different types are designed for different workloads and requirements.

Why change the instance type?
If an instance is underutilized, choosing a smaller instance type can help reduce costs and avoid wasting resources, as long as the workload can still perform properly.
