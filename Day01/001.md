Day 01 - EC2 Key Pair: Created an RSA key pair named nautilus-kp. Key pairs are used to securely authenticate and access EC2 instances, typically through SSH. The private key must be kept secure, while the public key is associated with the instance.

 ---Aws client commands

- List all key pairs in the region
aws ec2 describe-key-pairs

- Check for a specific key pair by name
aws ec2 describe-key-pairs --key-names "your-key-name"

-  Check in a specific region (if not using default profile region)
aws ec2 describe-key-pairs --region us-east-1
