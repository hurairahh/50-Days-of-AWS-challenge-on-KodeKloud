The task involved creating an IAM role named iamrole_jim with AWS Service as the trusted entity, using EC2 as the use case, and attaching the policy iampolicy_jim.

What is an IAM Role?
An IAM role is an identity that provides temporary permissions to AWS resources or services without requiring long-term credentials.

Why use an IAM Role with EC2?
An EC2 instance can assume an IAM role to access other AWS services securely. For example, an EC2 instance might need permission to read from an S3 bucket. Instead of storing AWS access keys on the server, the permissions can be provided through an IAM role.
