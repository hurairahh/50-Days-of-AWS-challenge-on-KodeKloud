What is an EBS Snapshot?
An EBS Snapshot is a point-in-time backup of an EBS volume. It can be used to restore data or create new EBS volumes from a previous state.

*Why use snapshots?
Snapshots provide a way to back up important data and recover it when needed, making them useful for data protection and disaster recovery.
