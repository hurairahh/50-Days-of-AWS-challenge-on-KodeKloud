Day 02 - Security Group: Created datacenter-sg in the default VPC and configured inbound rules for HTTP (80) and SSH (22). Security Groups act as virtual firewalls, controlling which network traffic is allowed to reach AWS resources.

HTTP (Port 80): Allows web traffic to reach the EC2 instance. It is used when you want to host a website or web application accessible over standard HTTP.
SSH (Port 22): Allows secure remote access to the EC2 instance through SSH. It is mainly used by administrators to connect to the server, run commands, configure software and manage the instance.

 ---Aws client commands

- List all security groups
aws ec2 describe-security-groups

- Check a specific security group by ID
aws ec2 describe-security-groups --group-ids sg-0123456789abcdef0

- Check a specific security group by name
aws ec2 describe-security-groups --group-names "my-security-group"
