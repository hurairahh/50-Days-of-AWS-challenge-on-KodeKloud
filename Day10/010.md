The task involved attaching the existing Elastic IP `datacenter-ec2-eip` to the `datacenter-ec2` instance in the **`us-east-1`** region.

🌐 **What is an Elastic IP?**
An Elastic IP (EIP) is a **static public IPv4 address** that can be associated with an AWS resource such as an EC2 instance.

📌 **Why is it useful?**
Unlike a normal public IP, an Elastic IP remains associated with your AWS account even when an instance is stopped or restarted. This provides a **consistent public IP address** for applications or services that need reliable network access.

*Elastic IPs are useful when a workload requires a stable public IP instead of relying on a dynamically assigned address.
