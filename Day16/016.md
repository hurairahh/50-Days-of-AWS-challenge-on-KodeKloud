The task involved creating an IAM user named iamuser_mariyam.

AWS CLI Command used

-- To Create IAM User
aws iam create-user --user-name iamuser_mariyam

What is IAM?
AWS IAM is a service used to manage identities and control access to AWS resources. It allows you to create users, groups, roles and policies and define what actions they are allowed to perform.
What is an IAM User?
An IAM user represents a person or application that needs to interact with AWS resources. Permissions can be assigned to control what that user can access and what actions they can perform.
