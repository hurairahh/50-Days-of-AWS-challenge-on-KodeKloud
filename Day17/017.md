The task involved creating an IAM group named iamgroup_james.

AWS CLI Command used

-- To Create IAM User group
aws iam create-group --group-name iamgroup_james

What is an IAM Group?
An IAM group is a collection of IAM users. Instead of assigning permissions to each user individually, permissions can be assigned to a group and its members inherit those permissions.

Why use IAM Groups?
Groups make it easier to manage permissions, especially when multiple users need the same level of access. They also help keep access management more organized and consistent.
