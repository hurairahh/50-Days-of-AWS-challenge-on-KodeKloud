Today's task involved enabling Versioning on the S3 bucket datacenter-s3-24413.

--- AWS Client Commands

List all S3 buckets
aws s3 ls

Check versioning status of a bucket
aws s3api get-bucket-versioning --bucket your-bucket-name

What is an S3 Bucket?
An S3 bucket is a container in Amazon S3 used to store and organize objects such as files, images, backups, logs and other data in the cloud.

What is S3 Versioning?
Versioning keeps multiple versions of an object whenever it is modified or deleted. This makes it possible to recover previous versions and helps protect against accidental deletion or unwanted changes.
