Day 14 of my 50 Days of AWS Challenge on KodeKloud.
Today’s task focused on EC2 instance termination and resource management.
The task involved deleting the EC2 instance named nautilus-ec2 in the us-east-1 region and verifying that its final state was Terminated.

Terminating an EC2 instance permanently removes the instance from AWS. Unlike stopping an instance, termination is generally irreversible, so it is important to make sure the resource is no longer needed before deleting it.

Removing unused resources helps keep AWS environments organized and can prevent unnecessary costs from running infrastructure.
